Pull-up / 背部

引体向上

稳住身体，肘向下拉，缓慢落回。

背阔肌、肘屈肌；提升垂直拉力。

本动作怎么安排

周一 · 上肢力量 A4 × 6–8

组间休息 · 2–3分钟起，未恢复时可延长

重量 / 难度 · 以余力和动作质量判断。若第6次已很勉强、不确定还能标准完成下一次，就不要为了凑8次继续借力；可减少次数、延长休息或增加辅助。

01 / 准备姿势

选择肩宽或略宽且舒适的正握；拇指环握，双腿微屈或交叠，收紧腹部避免摆动。

02 / 一次完整动作

  1. 从受控悬垂开始，肩胛与手肘协调运动，不必刻意分成先肩胛、后手臂两段。
  2. 肘向身体两侧下方移动，把身体拉高；不靠伸脖子把下巴硬凑过杆。
  3. 在舒适活动范围内下降约2秒，手肘逐渐伸直，允许肩胛自然上转。

03 / 呼吸与核心

上拉时呼气，下降时吸气；保持腹部张力。

04 / 常见错误 → 调整

摆腿借力 → 减少次数，必要时使用辅助器械。

缩短回程 → 降低难度，恢复受控且无痛的活动范围。

05 / 每组完成自检

  • 身体没有持续前后摆动，最后一次也不靠蹬腿。
  • 上拉与下降的活动范围大致一致，不用伸脖子补高度。
  • 最后几次可以变慢，但仍能主动控制下降。

06 / 难度调整与进步

做不稳时 · 次数不足时，用辅助引体器械降低难度；先保留完整、受控的回程。

稳定之后 · 先让各组在相同标准下稳定完成目标次数，再减少辅助或考虑小幅负重。

个人应用 · 原计划4×6–8。手臂参与正常，酸胀位置不能单独判断背部是否参与。

Chest-supported Row / 背部

胸托划船

胸贴垫，肘向后，回程不甩。

背阔肌、上背及肘屈肌；减少躯干借力。

本动作怎么安排

周一 · 上肢力量 A3 × 6–8

组间休息 · 1–2分钟起，以动作稳定为准

重量 / 难度 · 用热身逐级确认当天工作重量；按目标次数完成后，通常还应能以同样姿势再做约2–3次。

01 / 准备姿势

哑铃版本将斜凳调到胸部能稳定承托的角度，双脚踩稳，哑铃下垂时不触地；器械版本调好胸垫与座高。两种版本都保持手腕与前臂对齐。

02 / 一次完整动作

  1. 让手肘向后移动，肩胛随拉动自然靠近，胸部始终贴垫。
  2. 拉到上臂与躯干大致齐平或舒适位置，停顿半秒，不强行把肘送得很远。
  3. 控制放回，让肩胛自然前伸；胸廓不塌陷，也不把肩胛全程锁死。

03 / 呼吸与核心

拉时呼气，放回吸气。

04 / 常见错误 → 调整

抬胸离垫 → 降低重量并重新调整靠垫。

手腕勾起 → 保持手腕稳定，用肘引导方向。

05 / 每组完成自检

  • 胸部保持接触靠垫，不在拉到顶端时抬起。
  • 手腕没有勾起，左右手拉动基本同步。
  • 回程能放慢，重量没有突然掉落。

06 / 难度调整与进步

做不稳时 · 先减重；器械靠垫应支持胸部且不妨碍呼吸，斜凳哑铃版本也要保证双脚稳定。

稳定之后 · 先增加受控次数，再使用器械或哑铃的最小重量增量。

个人应用 · 原计划3×6–8；器械与哑铃版本都可，按实际设备调整。

Lat Pulldown / 背部

高位下拉

大腿固定，肘向下，缓慢回放。

背阔肌与肘屈肌；垂直拉力。

本动作怎么安排

周一 · 上肢力量 A3 × 8–10

组间休息 · 1–2分钟起，以动作稳定为准

重量 / 难度 · 用热身逐级确认当天工作重量；按目标次数完成后，通常还应能以同样姿势再做约2–3次。

01 / 准备姿势

压腿垫固定大腿，脚踩地；握距选择舒适位置，躯干仅轻微后倾。

02 / 一次完整动作

  1. 肩胛与手肘协调下拉，杠向上胸靠近；不做颈后下拉。
  2. 保持躯干角度基本不变，到舒适底部停顿，不强拉到胸口。
  3. 控制回程，手臂向上伸展，允许肩胛自然上转，不让配重撞落。

03 / 呼吸与核心

下拉呼气，回程吸气。

04 / 常见错误 → 调整

大幅后仰甩重量 → 减重，固定躯干角度。

回程突然松手 → 保持握持并慢慢放回。

05 / 每组完成自检

  • 下拉前后躯干角度基本稳定，不靠大幅后仰。
  • 回程可受控伸展手臂，配重没有撞落。
  • 肩肘在舒适范围内协调运动，不强拉杠碰胸。

06 / 难度调整与进步

做不稳时 · 减轻配重，重新固定大腿；握距先选肩部舒适的位置。

稳定之后 · 先把每组8–10次做稳，再增加最小配重；更重不应换来更大的后仰。

个人应用 · 原计划3×8–10。既往80kg记录不能代表当前工作重量，不预填重量。

Incline Dumbbell Press / 胸部

上斜哑铃推胸

脚踩稳，肘在手下，斜向上推。

胸肌、三角肌前束和肱三头肌。

本动作怎么安排

周一 · 上肢力量 A3 × 8–10

组间休息 · 1–2分钟起，以动作稳定为准

重量 / 难度 · 用热身逐级确认当天工作重量；按目标次数完成后，通常还应能以同样姿势再做约2–3次。

01 / 准备姿势

本手册选用哑铃版本；靠背约15–30°，脚踩稳，肩胛有稳定支撑，哑铃放在胸侧。

02 / 一次完整动作

  1. 手腕大致在肘上方，肘与躯干约30–60°，控制下降。
  2. 下放到肩部舒适且前臂能稳定承重的位置，不强求哑铃低于胸口。
  3. 向上推至手臂接近伸直，哑铃不相撞，肩膀不向前顶。

03 / 呼吸与核心

下降吸气，推起呼气；腹部收紧。

04 / 常见错误 → 调整

靠背过陡 → 调低角度，减少肩前侧主导。

为深度牺牲肩稳定 → 缩小幅度并减重。

05 / 每组完成自检

  • 左右哑铃轨迹基本同步，手腕没有明显后折。
  • 下放末端肩部仍有稳定支撑。
  • 推起时臀部留在凳上，哑铃不相撞。

06 / 难度调整与进步

做不稳时 · 降低重量或缩小无痛下放幅度；先用轻哑铃熟悉安全起坐和收尾。

稳定之后 · 在相同凳角、握法与幅度下先完成次数上限，再用最小哑铃增量。

个人应用 · 原计划3×8–10；如原日程使用器械上斜推胸，以器械设置为准。

Lateral Raise / 肩部

侧平举

肘带动，向外上方抬，不甩。

三角肌中束；肩部外展力量。

本动作怎么安排

周一 · 上肢力量 A3 × 12–15

组间休息 · 1–2分钟起，以动作稳定为准

重量 / 难度 · 用热身逐级确认当天工作重量；按目标次数完成后，通常还应能以同样姿势再做约2–3次。

01 / 准备姿势

双脚站稳，肘微屈；手臂在身体两侧略偏前的位置，握持自然，不刻意倒水。

02 / 一次完整动作

  1. 肘引导向两侧抬，手与肘大致同步。
  2. 抬到接近肩高或无痛范围即可，躯干不侧摆。
  3. 用约2秒放下，避免哑铃靠惯性反弹。

03 / 呼吸与核心

抬起呼气，放下吸气。

04 / 常见错误 → 调整

甩动、蹬腿 → 减重，必要时坐姿完成。

强行手腕翻下 → 改成自然握姿，不追求倒水动作。

05 / 每组完成自检

  • 抬起时躯干不侧摆、不用蹬腿。
  • 肘角大致稳定，不变成屈肘拉起。
  • 下放能控制，头颈没有跟着前伸。

06 / 难度调整与进步

做不稳时 · 换轻哑铃，必要时改坐姿；抬举高度按无痛且可控制的范围。

稳定之后 · 先稳定完成12–15次；重量跳档较大时，优先保持动作和回程控制。

个人应用 · 原计划3×12–15。肩胛自然运动，避免用“肩膀全程压低”限制它。

Dumbbell Curl / 手臂

哑铃弯举

肘位稳定，弯起不摆，落下不掉。

肱二头肌及其他肘屈肌。

本动作怎么安排

周一 · 上肢力量 A2 × 10–12

组间休息 · 1–2分钟起，以动作稳定为准

重量 / 难度 · 用热身逐级确认当天工作重量；按目标次数完成后，通常还应能以同样姿势再做约2–3次。

01 / 准备姿势

站稳，膝微屈，手臂垂在身体两侧，手腕与前臂对齐。

02 / 一次完整动作

  1. 保持上臂大致稳定，屈肘把哑铃举起，手掌可自然转向上。
  2. 在肘部舒适范围内到顶，不用腰后仰帮忙。
  3. 缓慢放下，肘逐渐伸直，不用惯性反弹。

03 / 呼吸与核心

举起呼气，放下吸气。

04 / 常见错误 → 调整

躯干后仰 → 减重或靠墙站。

手腕弯折 → 改轻重量或舒适的锤式握法。

05 / 每组完成自检

  • 肘部没有随着每次弯举大幅前移。
  • 腰背不后仰，膝部不反复蹬伸借力。
  • 手腕与前臂对齐，下降没有突然掉落。

06 / 难度调整与进步

做不稳时 · 减少重量；可以靠墙减少摆动。锤式握法只在实际无痛时作为可选版本。

稳定之后 · 先增加标准次数；加重量后如果明显摆腰，就回到原重量。

个人应用 · 原计划2×10–12；手腕不适时只选无痛握法与幅度。

Barbell Back Squat / 腿臀

杠铃深蹲

脚踩稳，撑住躯干，髋膝一起下。

股四头肌、臀肌与躯干稳定。

本动作怎么安排

周二 · 下肢力量 A4 × 4–6

组间休息 · 2–3分钟起，未恢复时可延长

重量 / 难度 · 用热身逐级确认当天工作重量；按目标次数完成后，通常还应能以同样姿势再做约2–3次。

01 / 准备姿势

设置安全杆；杠铃放在上背肌肉承托处，不直接压颈部。站距与脚尖外展按髋部舒适度调整，足跟、前脚掌内外侧均有支撑。

02 / 一次完整动作

  1. 吸气并让腹部周围撑紧；髋膝协调屈曲下蹲，重心大致在全脚掌。
  2. 膝盖大致跟随脚尖，允许自然前移；下到能够维持平衡和躯干控制的深度。
  3. 推地站起，让髋与肩一起上升，避免先抬臀再用腰顶。

03 / 呼吸与核心

每次下蹲前吸气建立腹压，保持躯干张力，过困难段后呼气；不要跨多次重复持续憋气。

04 / 常见错误 → 调整

足跟抬起 → 检查站距、活动度和重量，必要时用举重鞋。

膝内扣或躯干塌陷 → 减重，重新控制轨迹。

05 / 每组完成自检

  • 全脚掌有稳定支撑，足跟不在底部抬起。
  • 膝盖大致顺着脚尖方向，躯干没有突然塌陷。
  • 起身时肩与髋协调上升，不先抬臀再顶腰。

06 / 难度调整与进步

做不稳时 · 减轻重量或暂时减少深度；先用徒手或轻杠确认平衡、安全杆与起身路线。

稳定之后 · 保持相同站位与可控深度；各工作组达到目标且保留余力后，再考虑最小重量增量。

个人应用 · 原计划4×4–6。使用安全杆或可靠保护，不测试极限重量。膝盖超过脚尖本身不等于错误。

Romanian Deadlift · RDL / 腿臀

罗马尼亚硬拉

微屈膝，髋后移，杠贴腿。

腘绳肌、臀肌；髋铰链能力。

本动作怎么安排

周二 · 下肢力量 A3 × 6–8

组间休息 · 2–3分钟起，未恢复时可延长

重量 / 难度 · 用热身逐级确认当天工作重量；按目标次数完成后，通常还应能以同样姿势再做约2–3次。

01 / 准备姿势

从站立持杠开始，脚约髋宽；膝微屈，杠在大腿前，肩部与背部保持张力。

02 / 一次完整动作

  1. 保持膝屈角度大致稳定，臀部向后移，杠沿腿前下降。
  2. 到腿后侧有明显拉伸且背部仍可控制的位置即停，不要求杠碰地。
  3. 脚踩地、髋向前伸展站起；顶部站直即可，不向后折腰。

03 / 呼吸与核心

下降前吸气撑紧躯干，起身过困难段后呼气。

04 / 常见错误 → 调整

越降越蹲 → 减少膝屈，把髋向后送。

为触地弯腰 → 提高最低位置，保留后侧张力。

05 / 每组完成自检

  • 臀部向后移动，膝角基本稳定，不越来越像深蹲。
  • 杠与腿保持接近，最低点不靠弯腰获得。
  • 顶部站直即可，不向后折腰。

06 / 难度调整与进步

做不稳时 · 用轻杠或哑铃练习髋后移；最低点以背部稳定和腿后侧张力为界。

稳定之后 · 先稳定最低位置与回程，再增加次数或重量；不要靠更低触地来证明进步。

个人应用 · 原计划3×6–8。训练感受可辅助调整，但不以酸痛作为效果标准。

Leg Press / 腿臀

腿举

骨盆贴垫，控深度，平稳推。

股四头肌、臀肌。

本动作怎么安排
